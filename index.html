About me.

I’m a Penetration Tester and Security Analyst with hands-on experience in Vulnerability Assessment and Penetration Testing (VAPT), Web and Network Security, and Threat Analysis. I’m skilled in using tools like Metasploit, Burp Suite, Nmap, and Wireshark, and proficient in Python and Bash scripting for automating security tasks and exploit development.

I’m CEH v13 trained, with practical exposure gained through labs, internships, and real-world cybersecurity projects. My experience spans OWASP Top 10 assessments, Active Directory exploitation, and OS-level vulnerability testing. I’m passionate about uncovering security weaknesses, creating detailed technical documentation, and continuously enhancing both offensive and defensive cybersecurity skills. Currently, I’m preparing to pursue CompTIA Security+ to further strengthen my professional credentials.
